# API de Funcionários

API REST desenvolvida com Node.js, Express e MySQL para gerenciamento de funcionários.

O projeto também possui um painel administrativo desenvolvido com HTML, CSS e JavaScript para visualizar os funcionários cadastrados.

---

## 🚀 Tecnologias

- Node.js
- Express
- JavaScript
- MySQL
- MySQL2
- dotenv
- Nodemon
- HTML5
- CSS3

---

## 📋 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar o desenvolvimento de APIs REST utilizando Node.js e Express, além da integração com banco de dados MySQL.

A aplicação permite consultar funcionários cadastrados no banco de dados e realizar novos cadastros através da API.

O projeto também possui um painel administrativo que consome a API e exibe os dados dos funcionários.
